Website part of ``event_waitlist``.

-  On a sold-out event, the disabled "Sold Out" button is replaced by
   **Join the waiting list**. In the ticket selection, a sold-out ticket
   gets a "Join the waiting list" link while other tickets are still
   available. The event list shows "Waiting list open".
-  Sign-up form with name, email, optional phone, number of seats and
   ticket, a privacy notice (editable with the website editor), a
   honeypot against bots and a clear message for duplicate emails.
-  Confirmation page with the position on the list.
-  The token pages (accept, decline, leave) are shown in the website
   layout.

Configuration
=============

Enable the waiting list on the event (see ``event_waitlist``). The
privacy notice on the form links to ``/privacy``; change the text or
link with the website editor on the form page.
